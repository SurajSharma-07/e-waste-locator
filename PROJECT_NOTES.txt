PROJECT CREATED FROM THE TWO UPLOADED PBL DOCUMENTS

Core stack:
HTML + CSS + JavaScript + Python/Flask + MySQL + Leaflet/OpenStreetMap

Important:
The uploaded documents require certified/verified facility information, but they
do not provide an actual verified facility dataset. Therefore this project does
NOT invent certification claims. Demo SQL records are marked Pending and are
hidden by the application until the team replaces them with genuinely verified
records.
